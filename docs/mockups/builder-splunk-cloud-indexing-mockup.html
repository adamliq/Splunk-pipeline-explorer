Review findings · Splunk Cloud profile

  • ERRORSyslog can't go directly to Splunk Cloud. Firewalls 1 → Splunk Cloud. Send it through the syslog server (SC4S) and HEC, or through a forwarder.
  • WARNForwarder credentials app not recorded on Universal Forwarder 1. Splunk Cloud only accepts forwarders that have the stack's credentials package.
  • WARNOutbound access not recorded. The Sydney network zone needs 9997 and 443 to acme.splunkcloud.com, and the stack's IP allow list needs the zone's egress addresses.
  • OKTLS on every handoff into Splunk Cloud (S2S 9997 and HEC 443).
  • OKDeployment Server manages forwarders only. No management links to Splunk Cloud.
