Move the rest of Tools: four tools, four drawer tabs

Route validation, the configuration draft, the connection template and the layout profiles leave the Tools panel, which scrolled sideways, for tabs in the Builder’s drawer, beside Review, Rules, Inventory, Trace and History. The menus open each tab, and each tool fits the drawer at every width. Every target scene is the real explorer with the prototype applied to Build 207; the “Today” scenes are Build 207 as shipped.

    The design in short

    Routes
    Route validation, beside Coverage, Review and Rules. Validate › Route validation… opens it.
    Config draft
    The configuration draft for the component or link selected, beside Inventory and Trace. Analyze › Configuration draft… opens it.
    Templates
    The connection template. Edit › Connection template… opens it.
    Layouts
    The layout profiles. Arrange › Layout profiles… opens it.
    Fitting
    Each tool lays itself out for the drawer’s width, from 600 px down to the 300 px the drawer can be dragged to, and on phones. Nothing scrolls sideways.
    Phones
    More’s Tools disclosure keeps a button for each of the four tabs.
    Unchanged
    What each tool does, the menus’ items and notes, the drawer’s other six tabs, and the drawer closing when something is selected from it.
