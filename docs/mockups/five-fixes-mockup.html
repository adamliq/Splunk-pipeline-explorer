MOCKUP · BUILD 206 TARGET · BUILD 205 + PROTOTYPE

Five fixes: Esc, the selection, syslog to Splunk Cloud, the Inspector and [source::] stanzas

Four fixes in the Builder and one in the Config view. Esc cancels a pending connection. A component added from the palette is the only one selected. A Syslog Source can no longer be linked to Splunk Cloud indexing. The Inspector is usable with nothing selected at every width. And a monitor finds the props.conf [source::] stanzas whose wildcards match its files. Every target scene is the real explorer with the prototype applied to Build 205; the “Today” scenes are Build 205 as shipped.

    The fixes in short

    Esc
    Esc cancels a connection waiting for its other end and keeps the selection, as Esc in the add-next list does. An open menu or popover, and a text field, still take the Esc first. With nothing pending, Esc is as before.
    Adding
    A component added from the palette, by click or drag, is the only one selected.
    Syslog to Cloud
    A Syslog Source can’t be linked to Splunk Cloud indexing: the handles and drags refuse, with the reason, and a palette click adds Splunk Cloud indexing unconnected and says why. A file that already has the link loads with it, and Build 148 marks it and offers “Insert Syslog Server between them”.
    The Inspector
    Opaque, and taking clicks and taps, whatever is selected, at every width.
    [source::]
    “...” is any run of characters, “*” any run within one path segment, “.” a dot, and the rest a regular expression, matched case-sensitively against the whole path. A monitor’s path can use “...” and “*” too, or name a directory. The stanza with the higher priority wins (100 for a literal one, 0 for a pattern, unless set), then the one first in ASCII order.
    Unchanged
    The Builder’s other Esc handling, the add-next list, what a Syslog Source can send to otherwise, the docked Inspector, and the Config view’s notes for a stanza that is the monitor’s path.
