    The design in short

    Port
    A link labelled Splunk-to-Splunk gets port 9997. A port stored in a file, 0 included, stays as stored.
    Esc
    Closes the menu, panel, popover, overlay or drawer that’s open, and keeps the selection. With nothing open, it clears the selection, as before.
    Phones
    Esc closes More and Planes, and keeps the selection.
    Below 1,280 px
    Components open over the canvas counts as open, so Esc closes it and keeps the selection. With the Inspector open over the canvas, Esc still clears the selection, which closes it.
    Splunk Cloud
    An Indexer in a load balancer’s pool can’t be converted to Splunk Cloud indexing. The status says why.
    Syslog
    A load balancer that passes syslog refuses Splunk Cloud with the syslog reason: when linking, in validation and for files.
    Title
    The drawer is “Topology tools”.
    Unchanged
    Every other port, the HEC load balancer’s reason, an Indexer fed straight by a Syslog Source (Build 148 flags it), and everything the drawer and menus do.
