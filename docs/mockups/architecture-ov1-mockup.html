Mission

Collect security telemetry from two data centres and AWS, keep two indexed copies across sites, and give the SOC searchable, alertable data within 60 seconds, 24×7.

Operational threads

  1. 1
    CollectWindows hosts run Universal Forwarders. Firewalls and appliances send syslog to a relay in each site. AWS services push CloudTrail and GuardDuty findings through Lambda to HEC.
  2. 2
    ForwardForwarders send Splunk-to-Splunk over TLS on TCP 9997 with indexer acknowledgement, to the indexers in their own site.
  3. 3
    Index and replicateThe multisite indexer cluster keeps two searchable copies, one in Sydney and one in Melbourne (RF 2 / SF 2).
  4. 4
    Search and detectThe search head cluster runs Enterprise Security correlation searches and serves dashboards to the SOC.
  5. 5
    Manage the fleetThe Deployment Server delivers apps and configuration to the forwarders over phone-home on TCP 8089. The License Manager tracks daily ingest.
  6. 6
    AuthenticateAnalysts and administrators sign in through the identity provider with SAML SSO and MFA. The model records the mechanism only, never credentials.
  7. 7
    RespondNotable events start SOAR playbooks and open tickets for the on-call analyst.
