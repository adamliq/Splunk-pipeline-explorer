MOCKUP · BUILD 221 TARGET · BUILD 220 + PROTOTYPE

The Config view follows expressions, packages, splits and filters, and says where the files act

Six changes to the Config view, prototyped on Build 220: four faults and two additions. The source type map follows the source types, the index and the queue an INGEST_EVAL names (53). A .spl app package opens, and so do a .zip and a plain .tar (54). With a source type chosen, the panel keeps the lines that give events that name (55). A monitor’s whitelist and blacklist decide which [source::] stanzas its files can match (17). The panel says where the files act, tier by tier and app by app. And the map folds its long runs of search-time lines. Every target scene is the real explorer with the prototype applied to Build 220; each “Today” scene is Build 220 as shipped, set up by the same steps. Seven of the sixteen scenes use the props.conf and transforms.conf of the Fortinet FortiGate Add-on for Splunk 1.6.10, which aren’t in the repository.

    The changes in short

    Expressions
    The map reads what each assignment of an INGEST_EVAL can give: the text values if(), case() and coalesce() lead to, each with its tests. A source type is followed as a REGEX’s is; an index, a queue, a host and an output are named. Where an expression can give something the map can’t name, “set by an expression” stays.
    Packages
    .spl, .tgz, .tar.gz, .tar and .zip, by what the file is and not by its name. A .spl file that is a pipeline’s text is still read as a pipeline.
    The list
    With a source type chosen, the panel and the view’s Matrix keep the transform that gives events that name, the TRANSFORMS- or RULESET- line that runs it, and a rename line that leads to it, each under its stanza’s header.
    Filters
    A [source::] stanza is left out for a monitor when no file it names can pass the monitor’s whitelist and blacklist. The monitor’s line says so. Where the page can’t tell, nothing changes.
    Tiers
    Under the panel’s summary: Universal Forwarder, Heavy Forwarder, Indexer, Search Head, each with the lines that take effect there, and a row for each app when there are several. A tile chooses its component in the strip; pressed again, all components.
    Folds
    In the map’s Search column, six or more EXTRACT-, REPORT-, FIELDALIAS-, EVAL- or LOOKUP- lines in a row fold to “13 FIELDALIAS- lines” and their first names. A fold stays as it was left for the visit.
    Unchanged
    The example’s maps; a REGEX split; the Matrix’s stages; a monitor with no filter; every other view.
