The source type map: one source type, followed through Splunk

A new section of the Config view. For the source type chosen in the panel, it draws what reads it and names it, what parses it, the index-time transforms its settings run, where its events go and what searches add, in five columns, with a line from each thing to what it names or does. Every target scene is the real explorer, with the prototype applied to Build 215, loaded with the Config view’s example or other files; the “Today” scene is Build 215 as shipped.

    The five columns

    ColumnIts stages’ pipelinesWhat it holds
    1. ReadEvery pipeline not below: the inputs’ own, the forwarder’s event breaking and structured parsing, HEC’sThe inputs that read it; the [source::] stanzas their paths match; [source::] and rule stanzas that name it; the CLONE_SOURCETYPE transforms that make it; props.conf settings applied where the data is read
    2. ParseTCP input, Parsing, Merging and Typing handoffs; Parsing and Merging pipelinesThe receiving ports in the files, when an input other than HEC reads it; the source type’s own card, with its parsing settings, its Splunk Web lines and the lines Splunk ignores; [host::], [default] and global settings
    3. TransformTyping pipelineEach TRANSFORMS- and RULESET- line with the transforms.conf stanzas it runs, in its order, and what each does; SEDCMD- and the other Typing settings
    4. Index or sendIndexing and TCP output handoffs, Forwarding and Indexing pipelines, Replication, Acknowledgement, Pipeline control, Post-index managementA card for each destination: an index, an output group, a drop, a copy, an indexed field, a rewrite; then what the indexer applies as it writes
    5. SearchSearch-time processingThe search-time settings in the order Splunk applies them, with the transforms and lookups they name

    In short

    Where
    Its own section in the Config view, between the files and the view’s Matrix, shown when files are loaded. Its chips are the panel’s Source type list: choosing in either moves both.
    Lines
    names it · a path matches a [source::] stanza, a listener takes a token’s events · copy · index · send · drop · field, rewrite, metadata.
    Settings
    Each with its stage chip, which shows the stage in the Matrix, and its line’s reference, which shows the line in the panel; secrets masked as in the panel.
    Components
    With a component chosen in the strip, what has no effect there fades, each card saying the reason once; destinations fade with their causes.
    Narrow
    The map scrolls sideways in its box when the window is narrower than it needs; at 900 px and below the columns stack and the lines go.
    Unchanged
    The panel, the view’s Matrix and every other view; the edit only exports six of the Config view’s functions.
