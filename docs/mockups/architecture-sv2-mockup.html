Purpose

How the system interfaces travel over the network: which network segment each system sits in, which system opens each connection and on what port, which connections cross a boundary, the bandwidth each boundary carries, and the firewall rules that follow.

Network paths

Each pair of segments that at least one connection crosses, in the direction the connections open. Average bandwidth is the OV-3 event volume spread over a day.
