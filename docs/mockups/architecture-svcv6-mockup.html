Purpose

Every service-to-service flow from SvcV-2 with the attributes a service owner commits to: the data, its format and rate, the timeliness and service level, and how it is protected. Each flow names the SV-1 system interfaces that carry it.

Carried by SV-1 interfaces

Each system interface and the service flows that ride on it. An interface with no flow, or a flow on a missing interface, is a gap between the service and system views.
