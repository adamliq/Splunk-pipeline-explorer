    How the Builder could generate this page

    OV-3 is the OV-2's resource flow table with every attribute spelled out. Most columns already exist in each connection's details or can be worked out from them. Two short fields are new, and two OV-2 fields are reused. Any empty attribute shows "Not set" here and in the open-questions appendix, which is how the page doubles as a completeness check.
