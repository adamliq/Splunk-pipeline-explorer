Builder: the Inspector in tabs

The Inspector shows one thing at a time (a component, a link, a selection, a container or the topology) and splits it into tabs, like draw.io’s Format panel. Every control Build 198 shows is in exactly one tab. Every scene is the real Builder with the prototype block appended to Build 198; the “Today” scenes are Build 198 as shipped.

    The rules in short

    One thing
    A component, a link, a selection (two or more), a container (opened from Containers after the last selection) or, with nothing selected, the topology.
    Tabs
    A component or link tab shows only when it has content. The last one chosen is remembered, for components and for links.
    Every control once
    For each of the 46 component types, and for links on all three planes, every control Build 198 shows is in exactly one tab.
    Marking
    Blocks stay where the app’s renderers put them. After each render the block marks each with its tab, and CSS shows one tab. A block it doesn’t recognise goes to Settings.
    Reveal
    Anything that focuses or scrolls to a field in another tab, such as inspecting a finding, switches to that tab first.
    History
    A control here that works through an existing one records one change, under that control’s label.
    Strip
    It sticks under the panel header. ← → Home End move between tabs. When the tabs don’t fit, it scrolls to the selected one.
    Free place
    From 761 px the alignment bar leaves the toolbar: align and distribute go to Selection, snap and grid to Topology.
    Phones
    The sheet gets the same tabs. With nothing selected it stays dimmed, as in Build 198. Focus canvas keeps the tabs too.
